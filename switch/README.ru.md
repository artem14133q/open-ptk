# Сборка под Nintendo Switch

[English](README.md)

`petka.nro` — homebrew-приложение: лаунчер и ядро движка поверх
[raylib-nx](https://github.com/luizpestana/raylib-nx) (raylib 6.0 на libnx,
звук через audren).

## Сборка

Нужен devkitPro с `switch-dev`, `switch-mesa` и `switch-libdrm_nouveau`.

```
cd switch
./raylib.sh        # один раз: берёт raylib-nx 6.0 и собирает его в deps/
make               # petka.nro
```

## Установка

Файлы игры кладутся на SD-карту в `sdmc:/switch/petka/` в той же раскладке,
что нужна десктопному лаунчеру (`ptk-unpack game` делает эту папку из
образов дисков): хранилища `.STR`, `disk1.id`..`disk3.id`, `intro.avi` и
`data1_out/`. `petka.nro` — в ту же папку. Сохранения и `Petka.ini` пишутся
туда же.

Запускать из homebrew-меню, лучше поверх игры (зажав R при запуске игры) —
тогда приложению доступна вся память консоли, а не урезанная память
апплета альбома.

`nxlink -s switch/petka.nro` отправляет его с компьютера и показывает там
его вывод.

## Управление

| | |
|---|---|
| сенсорный экран | указатель переходит туда; касание — клик |
| левый стик, крестовина | двигают указатель (крестовина — по пикселю) |
| A | клик |
| B | правая кнопка: звезда, положить предмет обратно |
| L / R | предыдущее / следующее действие курсора |
| X | чемодан |
| Y | карта |
| + | панель (меню, настройки, сохранение) |
| - | назад (Esc) |
| ZL / ZR | экран загрузки / сохранения |
| нажатие правого стика | отладочный экран |

Картинка — игровые 640x480 в полтора раза, 960x720 посередине экрана.

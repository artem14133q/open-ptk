# Сборка под Nintendo Switch

[English](README.md)

`petka.nro` — homebrew-приложение: лаунчер и ядро движка поверх
[raylib-nx](https://github.com/luizpestana/raylib-nx) (raylib 6.0 на libnx,
звук через audren).

## Сборка

Нужен devkitPro с `switch-dev`, `switch-mesa` и `switch-libdrm_nouveau`.

```
cd switch
./raylib.sh        # один раз: берёт raylib-nx 6.0 и собирает его в deps/
./ffmpeg.sh        # один раз: собирает FFmpeg 7.1 с форматами роликов в deps/
make               # petka.nro
```

## Установка

Файлы игры кладутся на SD-карту в `sdmc:/switch/petka/` в той же раскладке,
что нужна десктопному лаунчеру (`ptk-unpack game` делает эту папку из
образов дисков): хранилища `.STR`, `disk1.id`..`disk3.id`, `intro.avi` и
`data1_out/`. `petka.nro` — в ту же папку. Сохранения и `Petka.ini` пишутся
туда же.

Запускать из homebrew-меню, лучше поверх игры (зажав R при запуске игры) —
тогда приложению доступна вся память консоли, а не урезанная память
апплета альбома.

`nxlink -s switch/petka.nro` отправляет его с компьютера и показывает там
его вывод.

## Установленное приложение (NSP)

Установленная игра хранит сохранения так же, как игры консоли: при запуске
консоль спрашивает, кто играет, и сохранения, `Petka.ini` и `extras.ini`
становятся сохранениями этого пользователя для приложения — они видны в
«Управлении данными» и не пропадают при переустановке. В первый раз в них
переносятся те, что NRO оставил в `sdmc:/switch/petka/`. (Сам NRO хранит их
на карте: он может работать под чужим приложением.)

`make nsp` делает `petka.nsp`: ту же программу как установленное
приложение — с иконкой на главном экране среди игр, запускается без
homebrew-меню и поэтому всегда со всей памятью консоли. Файлы игры остаются
на своём месте, в `sdmc:/switch/petka/`.

```
./hacbrewpack.sh   # один раз: hacBrewPack в deps/ и логотип запуска
make nsp           # petka.nsp
```

Нужны собственные ключи консоли, `prod.keys`, снятые с неё Lockpick_RCM, в
`~/.switch/prod.keys` или в `.switch/prod.keys` в корне репозитория
(`.gitignore` не пускает его в репозиторий), или по пути из `PETKA_KEYS`: ими шифруется
содержимое приложения. Ключом Nintendo оно не подписано, поэтому консоль
запускает его только с патчами подписей (sigpatches) для своей прошивки.
Ставится как любой NSP (DBI, Tinfoil, Goldleaf). ID приложения —
`0100F35700A50000` (`nsp.sh`, `petka.json`).

`make nsp-full` делает `petka-full.nsp` — то же, но с игрой внутри: один
файл для установки, около 2 ГБ, на карту ничего копировать не нужно. В нём
файлы из списка `assets.txt` — только те, что читает лаунчер, — взятые из
папки игры, которую называет `PETKA_ASSETS` (в той же раскладке, что нужна
десктопному лаунчеру; её делает `ptk-unpack game`):

```
PETKA_ASSETS=~/ptk1-files make nsp-full
```

Такое приложение читает игру из себя. Внутри — файлы
оригинальной игры: этот NSP только для своей консоли, раздавать его нельзя.

## Вторая игра

Тот же `petka.nro` запускает и «Петьку 2: Судный день»: игра читается из
папки, где лежит NRO, если там же лежит её `main.str`, и сохранения
хранятся там же. Поэтому файлы второй игры (папку делает `ptk-unpack game`)
кладутся вместе с копией `petka.nro` в `sdmc:/switch/petka2/`, а первая игра
остаётся в `sdmc:/switch/petka/`.

Устанавливаемое приложение для неё собирается так же, с `PETKA_GAME=2`: свой
ID (`0100F35700A60000`), название и иконка (`icon2.jpg`, картинка
стартового меню), свои сохранения, `sdmc:/switch/petka2/` для файлов игры и
`assets2.txt` — список файлов для полного варианта (около 550 МБ):

```
PETKA_GAME=2 make nsp                                  # petka2.nsp
PETKA_GAME=2 PETKA_ASSETS=~/ptk2-files make nsp-full   # petka2-full.nsp
```

Её ролики сжаты Indeo 5: `ffmpeg.sh` теперь собирает и этот декодер
(запустите его заново, если `deps/ffmpeg` собран раньше).

## Управление

| событие | описание |
|---|---|
| сенсорный экран | указатель переходит туда; касание — клик |
| левый стик, крестовина | двигают указатель (крестовина — по пикселю); рядом с мелким предметом указатель притягивается к нему |
| A | на предмете: звезда действий для него; на полу: идти туда |
| левый стик при открытой звезде | указывает действие; A выполняет его, середина открывает чемодан, чтобы выбрать предмет для объекта |
| B | убрать звезду, закрыть чемодан, вернуть предмет; в диалоге — следующая фраза |
| вверх / вниз в меню диалога | выбор реплики (A — сказать) |
| L зажата / R зажата | курсор идёт / посылает Чапаева |
| X | чемодан: вверх, вниз, влево, вправо — по предметам, L / R — листать страницы |
| Y | карта |
| + | панель (меню, настройки, сохранение) |
| - | меню «Дополнительно»: вид ЭЛТ, подложка под текстом, подсветка предметов, притяжение указателя |
| ZL / ZR | экран загрузки / сохранения |

Картинка — игровые 640x480 в полтора раза, 960x720 посередине экрана, через
шейдер, имитирующий ЭЛТ-монитор (`launcher/src/crt.c`: строки развёртки,
выпуклое стекло, полосы люминофора); включается и выключается в меню
«Дополнительно» (-), на десктопе ещё и F4.

Ролики декодируют библиотеки FFmpeg, собранные в программу (`ffmpeg.sh`:
только демультиплексор AVI, Indeo 3, Microsoft Video 1, MS ADPCM и PCM);
десктопный лаунчер вместо этого запускает программу ffmpeg.

## Журнал с консоли

Положите пустой `trace.txt` в `sdmc:/switch/petka/` — лаунчер будет писать
журнал (сообщения скрипта, клипы, звуки) и сообщения raylib в
`sdmc:/switch/petka/petka.log`, построчно. Удалите файл — журнал
выключится. При запуске через nxlink (`nxlink -s petka.nro`) вывод идёт на
компьютер.

Иконка (`icon.jpg`) — обложка коробки игры целиком, вписанная в 256x256,
с чёрными полями сверху и снизу.

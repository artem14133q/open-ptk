# reloaded

[In English](README.md)

Достаёт из «Петьки 2: Судный день» Reloaded (Steam, 2016) картинки, которых
нет в самой игре, и кладёт их в папку игры архивом `RELOADED.STR` — того же
вида, что архивы игры. Когда в меню «Дополнительно» включены восстановленные
диалоги, лаунчер показывает их там, где сценарий просит клип, которого нет в
таблицах ресурсов игры.

```
pip install UnityPy Pillow
python3 reloaded.py <папка Reloaded> <папка игры>
```

Папка Reloaded — та, где лежит `petka2_Data`. Ничего из Reloaded в этом
репозитории нет: архив собирается из вашей собственной копии.

Что берётся:

- пасечник на пасеке, мертвецки пьяный (`DEDVSE` в Reloaded, спрайт
  `S-T-22__001`): после того как он отдал очки, сценарий показывает его
  вместо трезвого, и разговор идёт о том, как быстро он успел, но картинки
  его в игре нет (нет ресурса 1111), и он пропадал.

Для Switch `RELOADED.STR` кладётся рядом с остальными файлами игры в
`sdmc:/switch/petka2/`; `PETKA_GAME=2 make nsp-full` берёт его, если он
есть в папке, которую называет `PETKA_ASSETS`.
